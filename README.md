# Bletbox — «Кто первый?»

Минимальный realtime-buzzer для викторин. Сервер определяет порядок по моменту получения WebSocket-событий; клиентские timestamps не используются.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. Чтобы телефоны в локальной сети могли подключиться по QR-коду, задайте доступный им адрес:

```bash
PUBLIC_ORIGIN=http://192.168.1.10:3000 npm start
```

На Windows PowerShell:

```powershell
$env:PUBLIC_ORIGIN='http://192.168.1.10:3000'; npm start
```

## Проверка

```bash
npm test
npm run check
```

## Архитектура

- `src/room-manager.js` — комнаты, раунды, очередь, фальстарты и вердикты;
- `src/server.js` — HTTP, QR и WebSocket-транспорт;
- `public/host.js` — интерфейс ведущего;
- `public/play.js` — мобильный интерфейс игрока и восстановление сессии.

Состояние хранится в памяти процесса — это осознанное ограничение первого прототипа. Для нескольких серверных инстансов слой `RoomManager` можно заменить на Redis-backed реализацию, сохранив WebSocket-протокол и интерфейсы.

## Независимые сайты

`portal/` — отдельный статический каталог игр Bletbox. Карточки ведут на разные origins, поэтому портал, «Бункер» и «Кто первый?» не зависят от доступности друг друга. Адреса игр задаются в `portal/games.js`.

`render.yaml` описывает две независимые Render-службы из этого репозитория:

- `bletbox-hub` — статический портал;
- `bletbox-who-first` — Node.js/WebSocket-сервис buzzer.
